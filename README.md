# Project Overview

BackroomFind is a responsive accommodation website developed to help users find affordable backroom rentals across South Africa.

The website allows users to browse available accommodation, search for properties, submit rental enquiries, contact the organisation, and view property locations through an interactive map.

Part 3 enhances the project through JavaScript functionality, dynamic content, interactive elements, form validation, SEO implementation, and improved user experience.

---

# Website Goals

The objectives of BackroomFind are to:

- Help users locate affordable rental accommodation.
- Connect tenants with landlords.
- Provide accurate room availability information.
- Allow prospective tenants to submit enquiries.
- Improve accessibility through responsive design.
- Enhance user experience using interactive web features.
